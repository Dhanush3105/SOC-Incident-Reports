# Analyst Notes – What I Learned

- Malware samples are identified across vendors using cryptographic hashes
- SHA-256 is the primary method to uniquely identify files
- Malware communicates with external domains for C2 and data exfiltration
- SSL certificates can link multiple malicious domains together
- YARA rules allow pattern-based malware detection
- MITRE ATT&CK helps standardize attacker behavior mapping
- User confirmation is critical in SOC investigations
